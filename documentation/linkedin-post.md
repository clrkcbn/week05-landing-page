🚀 Week 5 – Client-Server Technologies

This week I designed and developed a **Responsive Product Landing Page** using **Laravel, Tailwind CSS, and Blade Components**. I built it for a neighbourhood grooming studio, "Fadehouse Barber Co." — a navbar, hero, six-feature grid, product showcase, three membership plans with a monthly/annual switch, testimonials, a booking form with inline validation, a closing call-to-action, and a footer.

🧠 Skills I practised this week:
• **Tailwind CSS** – utility-first styling driven by a small set of design tokens (one accent colour, one type scale, one spacing rhythm, one radius system).
• **Blade Components** – 12 reusable components, so each section is a short list of `<x-…>` tags instead of copy-pasted HTML and one fix updates every instance.
• **Responsive Design** – mobile-first, tested at 390 / 820 / 1280 / 1440px with Flexbox and CSS Grid.
• **UI/UX** – light/dark mode, hover/focus/active states, reduced-motion support, a skip link, and 4.5:1 contrast.

Comparing my initial unstyled prototype with the final version showed how much thoughtful UI decisions improve both user experience and maintainability. The structure came first; styling is what turned a stack of text into something people can actually scan and act on.
